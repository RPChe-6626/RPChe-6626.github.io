Basic Concepts of Covariance

由于本人只学过概率论，所以在这里简单的复习一点协方差的意义和性质。

一维协方差

  • 对于概率空间 $(\Om, \mc F, \mb P)$ 上的两个随机变量 $X, Y$ ，定义其协方差为

    协方差的定义与方差相仿，即有 $\V{X}=\cov(X, X)$ ，然而协方差度量的量与方差不同。回忆方差度量的是随机变量偏离其均值的程度，而协方差度量的是两随机变量 $X, Y$ 变化的相关程度。即

    • 若 $X, Y$ 偏离其期望的方向在期望意义上相同，则协方差为正，且 $X, Y$ 的同向偏离程度越大，协方差的绝对值越大。

    • 若 $X, Y$ 偏离其期望的方向在期望意义上相反，则协方差为负，且 $X, Y$ 的异向偏离程度越大，协方差的绝对值越大。

    这给出了协方差清晰的度量意义：两随机变量变化的相关程度。协方差具备一些计算上的性质：

    1. 双线性性。
    2. 对称性：$\cov(X, Y)=\cov(Y, X)$ 。
    3. 协方差的计算式：$\cov(X, Y)=\E{XY}-\E{X}\E{Y}$ 。

    这些性质是容易验证的。特别的，容易看出独立随机变量的协方差为 $0$ ，但反过来不一定成立。考虑反例：

    • $\Om={-2, -1, 0, 1, 2}, \mc F=2^\Om, \mb P=\unif(\Om)$ ，定义随机变量 $X$ 为单位映射，$Y=X^2$ 。显然，$X, Y$ 并不独立，然而容易计算得到 $\cov(X, Y)=0$ 。

    这实际上反映出协方差只能度量两个随机变量的线性相关程度[1]，上例中的二次相关性就被完全忽视了。另外和的方差也可以由协方差写出：

相关性

  • 我们说过协方差度量了两个随机变量变化的相关程度。然而如果要比较不同随机变量对的相关程度，协方差就不适用了。这本质上是量纲的问题——不同随机变量的量纲不同，当量纲变化时，即使同一随机变量对的协方差也会变动。因此一个简单看法就是，要度量相关性，我们需要对协方差做标准化。为此，对随机变量 $X, Y$ 分别做标准化，即定义

    定义其为随机变量 $X, Y$ 的相关系数，记作 $\cor(X, Y)$ 。相关系数具备良好的性质：

    1. 由 Cauchy-Schwartz 容易得到，相关系数总是介于 $[-1, 1]$ 之间。
    2. 相关系数取 $1$ ，当且仅当存在 $a, b\in\mb R, a>0$ 使得 $Y=aX+b$ a.s. 。
    3. 相关系数取 $-1$ ，当且仅当存在 $a, b\in\mb R,a <0$ 使得 $Y=aX+b$ a.s. 。

    其中第 2、3 条性质在直观上很明确：既然协方差度量的是两个随机变量的线性相关程度，那么当相关性最大，即相关系数的绝对值取到 $1$ 时，两个随机变量必须是完全线性相关的。要严格证明该性质，我们要从更高的视角来看协方差，即内积线性空间。

随机变量的内积线性空间

  • 现在考虑概率空间 $(\Om, \mc F, \mb P)$ 上的全体二阶矩存在的随机变量，定义其上的实线性空间，使得其中的每一向量元素 $[X]$ 为全体与 $X$ 几乎处处相等的随机变量的等价类，记作 $L^2(\Om, \mc F,\mb P)$ ，容易验证其却为一线性空间。定义 $L^2(\Om, \mc F, \mb P)$ 上的内积，使得对于任意 $X, Y$ ，有 $\inn{X, Y}=\E{XY}$ ，容易验证其却为一内积。[2]

    特别的，对于离散概率空间，以上的定义尤其直观。若假设 $\Om$ 上所有元素的概率质量为正，则 $L^2(\Om, \mc F,\mb P)$ 的向量元素恰为全体 $\Om\to \mb R$ 的映射，并且该线性空间的维度恰为 $|\Om|$ 。进一步，可以证明内积线性空间 $L^2(\Om, \mc F,\mb P)$ 同构于 $|\Om|$ 维欧式空间 $\mb R^{|\Om|}$ 。为此，任取 $L^2(\Om, \mc F,\mb P)$ 上的一组单位正交基 ${e1, \cdots, e{|\Om|}}$ ，则任意向量 $v\in L^2(\Om, \mc F,\mb P)$ 具备坐标 $(a1, \cdots, a{|\Om|})\in\mb R^{|\Om|}$ 。由内积的性质，此时任意 $u, v\in L^2(\Om, \mc F,\mb P)$ 的内积都唯一对应其坐标空间上的欧式内积。因此基 ${e1, \cdots, e{|\Om|}}$ 便诱导出 $L^2(\Om, \mc F,\mb P)$ 与 $\mb R^{|\Om|}$ 的同构。

    更一般的，有限维内积空间总是同构于欧式空间。在这一视角下，任意中心化的随机变量[3]$X, Y$ 的协方差恰为其在 $L^2(\Om, \mc F,\mb P)$ 上的内积，此时相关对数便对应该线性空间中的夹角 $\cos(\ta)$ ：

    1. 若两向量同向，则其夹角（相关系数）为 $1$ 。
    2. 若两向量反向，则其夹角（相关系数）为 $-1$ 。
    3. 若两向量正交，则其夹角为 $0$ 。

    一般的，我们也会在连续概率空间中沿用这些看法，尽管此处并不会给出证明。

  • 以上，一个重要的看法是相关系数对应中心化随机变量在 $L^2(\Om, \mc F,\mb P)$ 中的夹角。如果我们只关注该部分，即考虑商空间 $L^2(\Om, \mc F,\mb P)/\span({1})$[4]，那么其恰好包含了全体中心化随机变量。该线性空间的维度为 $|\Om|-1$ ，因其可以看作在 $L^2(\Om, \mc F,\mb P)$ 上加入了中心化约束，恰为一线性约束。现在我们在中心化随机变量的线性空间中考虑，由 Cauchy-Schwartz 的基本性质，其取等当且仅当向量 $X, Y$ 同向，即存在标量非零标量 $c$ 使得几乎处处成立。对于非中心化随机变量便有：这便证明了相关系数的性质 2, 3 的必要性。至于充分性，是容易验证的。

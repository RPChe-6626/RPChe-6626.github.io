Optimization of RL

  • Someone says RL has different optimization aspect from ordinary supervised learning where typically a scalar function is minimized. In RL we instead seek to find an optimal policy, which might be more complicated. However I still think there should be no foundamental difference, because the modeling will be written as a rigorous optimization problem anyway. Concretely, there are main questions
    1. How to define the optimality of a policy.
    2. How to solve for the optimal policy.
    In this installment we'll answer the first question. It is worth mentioning that in RL we also refer to "optimization" as "control". Because if we consider the optimization as a step-wise problem, we have to control each movement of the agent. I think this perspective may originate from robotics.

Other Terminologies

  • There are a few terminologies in RL, mostly to distinguish the methods used for optimization for policy. We'll briefly introduce them at the beginning of the article.

    • Model-Based and Model-Free. The "model" here refers to dynamics models and reward models4, instead of any machine learning models. Model-based methods explicitly use dynamics models and reward models in optimization. In contrast, model-free methods do not explicitly rely on these models. For example, they may operate directly on value functions or Q-functions.
    • Planning and Learning. Planning and Learning are both realizations for control. Planning refers to using known or learned environment models, which consist of dynamics and reward models, to improve polices directly or indirectly. While learning refers to using samples collected from the environment. Note that it is natural that we use learning and planning simultaneously in one method. For example we can first learn an environment model and then use it in planning for an optimal policy.
    • Tabular and Function Approximation. When action and state spaces are small enough to enumerate, we typically employee tabular methods to put all the information in tables. When these spaces are too large, we'll use function approximation methods instead to approximate the quantities with function classes.
